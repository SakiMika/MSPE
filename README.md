# MapleStory Pirate Edition — Nintendo DS (MSPE)


| Phím NDS | Tác vụ / phím WIPI |
|---|---|
| D-pad (↑ ↓ ← →) | Di chuyển, mã `-1`, `-2`, `-3`, `-4` |
| **A** | **OK / EZ / FIRE**, mã `-5` |
| **B** | **Trở lại / CLR**, mã `-16` |
| **X** | Số `0` |
| **Y** | Dấu `*` |
| **R** | Dấu `#` |
| **L + A** | Số `1` |
| **L + B** | Số `3` |
| **L + X** | Số `7` |
| **L + Y** | Số `9` |
| **START** | Call, mã `-10` |
| **SELECT** | **Không sử dụng** (không gửi phím, không chuyển màn, không thể gán lại) |
| **L** (nhấn riêng) | Không có tác dụng |

**Lưu ý:** Phím số `5` **không được gán mặc định**. Nhấn `L` cùng
`A/B/X/Y` sẽ gửi phím tổ hợp tương ứng thay vì gửi thêm phím đơn.

**Chỉnh phím:** Chạm nút **LOG** ở màn hình cảm ứng (màn dưới),
sau đó chọn **SINGLE** để gán một phím NDS cho tác vụ WIPI, hoặc
**COMBO** để gán tổ hợp hai phím. **SELECT luôn được để trống**,
kể cả trong công cụ gán phím. Đóng LOG để hiện lại phần dưới của màn chơi.

**Tổ hợp kỹ thuật:** Giữ `X + Y` rồi nhấn `START` để thoát bản diagnostic
(cơ chế có sẵn trong source, không phải phím chức năng MapleStory).
